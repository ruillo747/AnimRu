# AnimRu

Аниме-онлайн на чистом JavaScript: онгоинги, каталог с фильтрами, топ-100,
свой плеер на hls.js, прогресс просмотра, аккаунты и боевой пропуск.

Источники данных: [Anilibria API v1](https://anilibria.top), вторая студия — Kodik.
Проект некоммерческий, видео отдаёт сторона источника.

## Запуск

Статический сайт, сборка не нужна. Нужен любой http-сервер
(service worker и WebCrypto не работают по `file://`):

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Настройка базы

1. Скопируйте `config.example.js` в `config.js` и подставьте свои значения.
   Без ключей приложение работает в локальном режиме (IndexedDB в браузере),
   с ключами — в облачном (Supabase).
2. В SQL-редакторе Supabase выполните `supabase/schema.sql`,
   затем `supabase/hardening.sql`.

`config.js` содержит только публичный anon-ключ, но всё равно держите его
вне репозитория для своих деплоев: вся защита данных лежит на RLS-политиках
из `supabase/`.

## Структура

| Файл | Назначение |
| --- | --- |
| `app.js` | роутер, главная, каталог, страница тайтла, плеер |
| `db.js` | слой данных: аккаунты, прогресс, оценки, комментарии |
| `auth.js` | модалка входа, блок аккаунта, синхронизация |
| `gamify.js` | уровни, XP, квесты, боевой пропуск |
| `social.js` | оценки и комментарии в интерфейсе |
| `extras.js` | тема, горячие клавиши, PWA, субтитры, подключение модулей |
| `kodik*.js` | второй источник видео |
| `catalog.js`, `schedule.js` | расширенный каталог и расписание |
| `offline.js` | скачивание серий в отдельный кэш |
| `polish.js`, `mobilefix.js` | доводка интерфейса и мобильные правки |
| `sw.js` | service worker: оболочка офлайн |

## Горячие клавиши

Вне плеера: `/` — поиск, `H` — главная, `C` — каталог, `T` — топ,
`P` — профиль, `R` — случайное, `S` — расписание, `K` — Kodik.

В плеере: `Space`/`K` — пауза, `←`/`→` — ±5 секунд, `↑`/`↓` — громкость,
`F` — полный экран, `M` — звук, `N` — следующая серия, `B` — предыдущая.
